|---|---|---|---|
| [Tripo API](https://platform.tripo3d.ai) (API 키 필요) | Tripo 이용 약관 | **조건부: 유료 플랜일 때만** | 약관 5.2.1: 무료 사용자가 만든 입력·결과물의 권리는 Tripo가 가짐. 5.2.2: 유료 사용자는 결과물 권리를 가짐([Terms](https://www.tripo3d.ai/terms), [상업적 이용 안내](https://www.tripo3d.ai/help/privacy-policy/how-to-use-tripo-models-commercially)). 무료 플랜 결과물은 게임에 넣지 않음. 선생님(개발자)만 쓰는 도구로, 학생 화면에서는 부르지 않음 |
| [Google Gemini API](https://ai.google.dev) `@google/genai` (API 키 필요, 모델 미정) | SDK는 Apache-2.0, 서비스는 [Gemini API 추가 약관](https://ai.google.dev/gemini-api/terms) | **제외** | 추가 약관: 18세 이상만 사용, 18세 미만을 대상으로 하거나 18세 미만이 쓸 가능성이 높은 앱·웹사이트에서 사용 금지. 수학 대륙은 초등학생용이라 해당됨. 교육용 예외 없음 |
| [표준국어대사전 오픈 API](https://stdict.korean.go.kr) (API 키 필요) | 약관 원문 미확인 | **보류** | 이 환경에서 사이트가 막혀 약관을 읽지 못함. 관련 자료는 공공누리(출처 표시) 기준을 안내함([개정 지침](https://www.korean.go.kr/front/etcData/etcDataView.do?mn_id=&etc_seq=126&pageIndex=1)). 약관 원문(이용 범위·상업적 이용·출처 표시·호출 한도)을 확인한 뒤 판정 |
