# Zelda-like 그림 출처 (흙절벽 · 바위 · 마을 소품)

- 원본: **Zelda-like tilesets and sprites** — ArMM1998
- 주소: https://opengameart.org/content/zelda-like-tilesets-and-sprites
- 라이선스: CC0 (퍼블릭 도메인). 출처 표기 의무는 없지만 감사의 뜻으로 적어 둬요.
- 확인: 2026-11-05 (OpenGameArt 페이지 설명·댓글, 사용자가 확인)

`Overworld.png`에서 흙절벽·풀 가장자리·바위·계단·마을 소품만 골라 `tools/build_zl_cliffs.py`로
지금 게임의 풀색(Ninja Adventure)에 맞게 색을 바꿨어요. 해골·뼈 그림은 가져오지 않았어요.

- `cliff_meadow.png` 들판 풀색
- `cliff_forest.png` 숲 풀색
- `cliff_pink.png` 분홍 꽃잎 땅 (큐베른 마을)
- `cliff_sand.png` 모래 (데시마르)
- `cliff_snow.png` 눈 (볼테라)
- `props.png` 바위·자갈·큰 바위·나무 계단
- `town.png` 시장 천막·긴 의자·나무 상자·과일 상자·화분·그루터기
- `fountain.png` 광장 분수 (3장면 움직임)
